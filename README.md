# 🎨 Lucas Provost – 그래픽 디자이너 포트폴리오 웹사이트

그래픽 디자이너 Lucas Provost의 포트폴리오 웹사이트입니다. 브랜드 디자인 전문성을 강조하고, 프로젝트 사례, 서비스 패키지, 고객 리뷰 등을 사용자 친화적인 UI로 소개합니다.

## 🔗 데모

👉 [실제 사이트 보기](#) (https://ryucandoit-lucas-provost.netlify.app/)

---

## 📌 주요 기능

- **인트로 애니메이션**: GSAP을 이용한 부드러운 fade-in 효과
- **프로젝트 슬라이드**: Swiper.js를 사용한 자동 슬라이드 갤러리 (마우스 오버 시 일시정지 기능 포함)
- **고객 리뷰 섹션**: 버튼 클릭으로 표시되는 리뷰 섹션 (슬라이드로 정렬된 후기)
- **패키지 견적 계산기**: 원하는 옵션을 선택하면 자동으로 가격 합산
- **FAQ 섹션**: 클릭 시 답변이 토글로 열림
- **이메일 문의 폼**: EmailJS를 이용한 이메일 전송 기능
- **반응형 웹**: PC/모바일 화면 최적화

---

## 🛠 사용 기술

- **HTML / CSS / JavaScript**
- **Swiper.js** – 슬라이더
- **GSAP + ScrollToPlugin** – 애니메이션 및 스크롤 제어
- **EmailJS** – 이메일 전송
- **Lodash** – scroll throttle
- **jQuery** – 마우스 이벤트 제어
- **Reset.css / Google Fonts / Font Awesome**
